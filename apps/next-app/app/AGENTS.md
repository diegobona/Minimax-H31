# MiniMax site page and route instructions

Before creating or editing files in this directory, read and follow [the site rules](../content/SITE-RULES.md).

These user-defined site requirements take precedence over conflicting generic TinyShip defaults, including framework parity and the location of new page copy. This site uses the Next.js app; public page copy lives in structured English objects under `../content/`, and existing shared i18n dictionaries remain protected.

The rules cover exact public URLs, server-rendered copy, metadata, shared layout, navigation, factual accuracy, indexing, permitted changes, and the per-page verification and commit workflow. Do not apply a TinyShip recipe that conflicts with them. Page implementation remains a separate user task.
