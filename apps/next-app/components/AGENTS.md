# MiniMax site component instructions

Before creating or editing files in this directory, read and follow [the site rules](../content/SITE-RULES.md).

Use existing shadcn/ui components without adding UI dependencies. Follow the site's component locations, CSS-variable tokens, server/client rendering boundaries, and English content-file convention. Header navigation and the footer disclaimer are shared through `../app/layout.tsx` and must not be duplicated in pages or tool components.

The user-defined site rules take precedence over conflicting generic TinyShip defaults. Existing authentication, payment, and other protected infrastructure remain protected.
